# Design specs

Written designs live here, one file per topic: `YYYY-MM-DD-<topic>-design.md`. `brainstorming` writes
them and `writing-plans` reads them — a plan's `Spec:` header points at one of these files, so a
design and the plan built from it travel together.

The design covers intent and the why, goals, non-goals, anti-goals, constraints, the approaches that
were considered with their trade-offs, the choices already made, and what is left to the builder. It
is approved before anything is built.

Implementation plans are not specs: they live in [`../plans/`](../plans/).
